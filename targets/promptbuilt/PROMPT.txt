Build a small web app called "Pantry Share" for a group house: people sign up, log in, and keep a private list of the food they bought (item name, price, notes), and can mark items as "shared" so housemates can see shared items on a common board. Each person should only see their own private items. Include sign up, log in, log out, adding, editing and deleting items, and a search box.

Technical requirements: plain Node.js with no npm dependencies. Put the server in server.mjs and the page in public/index.html. Listen on 127.0.0.1 using the port in the PORT environment variable (default 4300). Store all data in a JSON file at the path in the PANTRY_DATA environment variable (default ./data.json). Keep it simple and working.
